# 台架散热笔记

## 冷板接触检查
同一台演示设备采用冷板将热量从模拟热源传给循环水。装配时先检查接触面是否清洁、导热界面材料是否覆盖主要发热区，再按夹具规定的次序紧固。记录基线功率、入口水温和热源表面温度。更换界面材料后重复相同工况，才能比较温差。单点测温不能区分接触热阻增大和流量降低，检查时应同时核对水温与流量读数。

## 并联支路的流量分配
演示回路用两条并联支路连接同一对集流器。支路两端的压差相同，弯头、软管长度或节流孔不同会使两路流量不同。调试时分别记录两条支路的读数和进出口压差，然后改变一处可调阻力再复测。总供水流量恒定并不能证明每个冷板都有相同流量。此说明是台架操作示例，阀门位置需要由实际仪表确认。

## 风道与旁路
风冷台架的气流应经过散热器翅片。如果盖板和散热器之间留有缝隙，部分气流可能绕过翅片。对照实验可以固定风机转速并比较封住缝隙前后的出风温度。测温点应保持原位，并等待温度接近稳定。风机铭牌的自由送风量与装入机箱后的实际流量属于不同工况。

## 传感器布置
把入口温度探头放在混合充分的管段，出口探头使用相同型号和采样间隔。记录通道名称、单位、安装方向和采样时间。如果两个探头在恒温水中存在偏差，先记录偏差再解释台架测得的温升。启泵瞬间的瞬态读数不适合直接代入稳态热平衡。

## 泵入口与排气
观察泵入口管段的透明观察窗，按台架的排气流程清除高点积气。间歇噪声可能来自气泡，也可能来自安装振动，应结合入口压力和流量变化逐项排查。每次只改变一个条件并记录原始读数。示例不提供设备制造商的允许入口压力或通用安全阈值。

## 稳态导热算例
用一块均匀平板说明一维稳态导热。设温差为 60 K、厚度为 0.005 m、面积为 0.002 m²、导热系数为 16 W/(m·K)，忽略边缘散热和界面热阻。代入 Q = k A ΔT / L 可得 384 W。这是给定边界条件下的算例，没有测量真实设备，也没有预测实际元件温度。
